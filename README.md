# 🎮 EsportsHub - Professional Esports News Website

A modern, fully responsive esports news platform built with Next.js, TypeScript, and Tailwind CSS. Features include article browsing, category filtering, search, and dynamic article pages - all statically generated for optimal performance.

## ✨ Features

- ⚡ **Next.js** with TypeScript for robust development
- 🎨 **Tailwind CSS** for professional, dark-themed UI
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🔍 Search articles by title
- 🏷️ Filter articles by game categories (LoL, Valorant, CS2, etc.)
- 📄 Dynamic article pages with rich content
- 🚀 Static site generation (SSG) for lightning-fast loads
- 🆓 **100% free hosting** on Vercel / Netlify

## 🛠️ Tech Stack

- **Framework**: Next.js (Pages Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Deployment**: Vercel / Netlify (free tier)
